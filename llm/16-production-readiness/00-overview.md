# Production readiness: контекст

Этот каталог не добавляет product features. Он доказывает, что реализованный scope можно безопасно собрать, мигрировать, наблюдать, восстановить и постепенно выпустить на low-budget managed infrastructure с локализацией персональных данных в РФ.

External account/resource creation, DNS, app store submission, production migration and secrets require explicit authorization.
