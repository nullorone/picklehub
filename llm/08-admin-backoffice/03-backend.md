# Этап 3. Backend администрирования

## Промпт агенту

Ты — старший инженер RBAC и аудита на NestJS. Реализуй минимальные API административной панели.

## Выполни

- Центральная политика разрешений, назначение ролей платформы только суперадминистратором и повторная
  аутентификация сессии для чувствительных действий.
- Переходы обращений, решения о слиянии площадок и обратимые ограничения пользователей с причиной и аудитом.
- Защити поиск от перебора и массового извлечения; ограничь частоту экспорта и скрывай чувствительные поля по роли.
- Добавь эксплуатационные метрики и оповещения о возрасте очереди, сбое записи аудита и повторном
  несанкционированном доступе.

## Приёмка

UI не может обойти политику; сбой аудита при необходимости откатывает защищённое изменение; понижение роли быстро
отзывает сессии и разрешения.
