# ADR-002: отдельная основа дизайн-системы

Дата: 2026-10-02. Статус: принято владельцем.

## Решение

По запросу владельца выполнить отдельную [DS01](../tasks/ds01-design-system-foundation.md) до завершения пилота.
Это уточняет ADR-001: основа DS создаётся сейчас, без замены интерфейса MVP и изменения статуса S19.

Корневой ds содержит общие токены, веб-компоненты и Storybook. Tailwind 4 и React 18 сохраняются.
Токены платформенно независимы; CSS создаёт отдельный адаптер. Прежний пакет @picklehub/tokens остаётся
совместимым фасадом. Для native позже потребуются собственные компоненты и адаптер размеров.

Ein UI служит ориентиром для прозрачности, рамок и теней. Первый Button написан самостоятельно;
Radix появится при необходимости сложного поведения. Источники: https://github.com/einui/einui и
https://storybook.js.org/docs/get-started/frameworks/react-vite.

## Последствия

Storybook — локальная песочница для совместной разработки; агент готовит конфигурацию, тесты и Button.
Card и TextField реализуются с владельцем отдельно. Никакой публикации и продуктовой миграции UI в DS01.

## Уточнение 2026-10-02: точное оформление EIN

Владелец отклонил самостоятельную зелёную кнопку DS01. В [DS02](../tasks/ds02-ein-button.md)
Button адаптируется непосредственно из исходника EIN Glass Button с сохранением вариантов, размеров,
градиента, теней и свечения. MIT-лицензия сохраняется в ds/THIRD_PARTY_NOTICES.md.

Токены EIN находятся в отдельной группе ein; CSS дизайн-системы использует эти значения.
Прежние theme/color сохраняются для совместимости Mini App. Каталог показывает актуальную палитру EIN.
Подключаются Radix Slot, CVA и утилиты объединения классов. Для asChild сохраняется семантика дочерней ссылки,
для кнопки — безопасный type=button; reduced motion отключает переходы и масштабирование.

## Уточнение 2026-10-03: Mini App использует DS

По прямому запросу владельца существующие экраны Telegram переводятся на @picklehub/ui-web.
DS03 заменяет локальные примитивы адаптерами Glass-компонентов, сохраняет контраст обеих тем
и выбор темы Telegram. Контракты и сценарии MVP не меняются; S19 и DS02 сохраняют статус.
