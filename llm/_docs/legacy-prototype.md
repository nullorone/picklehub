# Legacy-прототип до prompt-first реструктуризации

- Дата фиксации: 2026-09-03.
- Состояние: React 18/Vite Telegram Mini App template с большим количеством незакоммиченных изменений и статическими mocks.
- Решение: не переносить старый production-код; использовать только как UX-reference, затем переписать приложения по контрактам.

## Полезные сценарии

- Нижняя навигация: главная, поиск, создание, клубы, профиль.
- Главная с header и быстрыми действиями; заготовки статистики, текущих игр и последних результатов были частично отключены.
- Создание с вкладками game/training/tournament; рабочей оставалась только статическая форма game.
- Экран счёта поддерживал singles/doubles, цели 11/15/21, старт/паузу, смену подачи и историю локального состояния.
- Турнирный mock показывал browse/my/create, статусы, сложность, цену и восемь названий форматов.
- Каталог клубов показывал поиск, расстояние, рейтинг, amenities, расписание, контакты, стоимость и membership state.
- Профиль имел mocks статистики, истории, достижений и настроек, но большая часть вкладок была отключена.
- Telegram template включал launch/init/theme debug routes и TON Connect demo, не относящиеся к продукту.

## Причины переписывания

- backend, API contract, auth, persistence, tests и бизнес-инварианты отсутствовали;
- UI смешивал Telegram-specific template и продуктовые mocks;
- данные, маршруты, naming и formatting были непоследовательными;
- TON Connect и GitHub Pages template settings не соответствуют выбранному MVP;
- старый код нельзя считать доказательством реализованной функции.

Незакоммиченные исходники сознательно не архивируются по решению владельца. Их удаление является необратимым вне локальных резервных копий.
