# Устаревший прототип до реструктуризации на основе промптов

- Дата фиксации: 2026-09-03.
- Состояние: шаблон React 18/Vite Telegram Mini App с большим количеством незакоммиченных изменений
  и статических заглушек.
- Решение: не переносить старый production-код; использовать только как ориентир UX, затем переписать приложения
  по контрактам.

## Полезные сценарии

- Нижняя навигация: главная, поиск, создание, клубы, профиль.
- Главная с заголовком и быстрыми действиями; заготовки статистики, текущих игр и последних результатов были
  частично отключены.
- Создание с вкладками игры, тренировки и турнира; рабочей оставалась только статическая форма игры.
- Экран счёта поддерживал одиночную и парную игру, цели 11/15/21, старт и паузу, смену подачи и историю
  локального состояния.
- Турнирная заглушка показывала просмотр, собственные турниры и создание, статусы, сложность, цену и восемь
  названий форматов.
- Каталог клубов показывал поиск, расстояние, рейтинг, удобства, расписание, контакты, стоимость и статус членства.
- Профиль имел заглушки статистики, истории, достижений и настроек, но большая часть вкладок была отключена.
- Шаблон Telegram включал отладочные маршруты запуска, инициализации и темы и демонстрацию TON Connect,
  не относящиеся к продукту.

## Причины переписывания

- backend, контракт API, аутентификация, постоянное хранение, тесты и бизнес-инварианты отсутствовали;
- UI смешивал платформенный шаблон Telegram и продуктовые заглушки;
- данные, маршруты, именование и форматирование были непоследовательными;
- TON Connect и настройки шаблона GitHub Pages не соответствуют выбранному MVP;
- старый код нельзя считать доказательством реализованной функции.

Незакоммиченные исходники сознательно не архивируются по решению владельца. Их удаление является необратимым вне локальных резервных копий.
