# DS03. Переверстать Telegram UI на DS

Прямой запрос владельца от 2026-10-03.

Использовать @picklehub/ui-web для списка, деталей, создания и редактирования игр,
кнопок авторизации, состояний загрузки и ошибок. Сохранить маршруты, API и поведение.
Telegram задаёт тему; приложение адаптирует контраст EIN к светлой подложке.

Приёмка: формат, lint, типы, тесты, контракты и сборка; браузерная проверка обеих тем
на 320 px и сценария создания игры. Результаты в журнале. Публикация не входит в задачу.
