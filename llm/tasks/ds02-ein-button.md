# DS02. Исправить Button по исходнику EIN

Статус: в работе. Прямой запрос владельца: воспроизвести Glass Button и его палитру.

## Основа

Прочитаны DS01, ADR-002, обзор, README и результаты предыдущего шага в журнале.
Эталон: https://ui.eindev.ir/docs/components/glass-button и
https://github.com/einui/einui/blob/main/registry/liquid-glass/glass-button.tsx.

## Приёмка

- [ ] Оформление, пять вариантов, четыре размера и glowEffect соответствуют исходнику EIN.
- [ ] Общие токены содержат EIN-палитру; прежние значения Mini App сохраняются отдельно.
- [ ] Storybook показывает варианты, размеры, иконки, свечение, disabled/loading и asChild.
- [ ] Сравнены реальные страницы EIN и Storybook, включая hover/active и узкий экран.
- [ ] Проверены доступность, клавиатура, ref, disabled и поведение формы.
- [ ] Формат, lint, типы, тесты, контракты и сборки проходят; результаты записаны в журнал.

## Границы

Исправление DS01: Card, TextField и продуктовый UI не реализуются. Использование исходника EIN — MIT,
с сохранением лицензии и указанием происхождения. Нативные компоненты остаются отдельным будущим шагом.
