# DS01. Основа дизайн-системы

Статус: выполнена 2026-10-02. Отдельная задача по прямому запросу владельца от 2026-10-02; S19 остаётся в работе.

## Контекст и решение

Перед реализацией прочитаны обзор проекта, README, ADR-001, S02 и журнал завершённых задач.
Владелец выбрал Tailwind, отдельный Storybook и один Button как образец. Следующие компоненты пишем вместе.
Архитектурное решение: [ADR-002](../_docs/adr-002-design-system.md).

## Приёмка

- [x] Пакеты ds/tokens, ds/web, ds/storybook используют npm workspaces и корневой lock-файл.
- [x] Единый источник токенов; прежние импорты Mini App совместимы.
- [x] Каталог токенов и Button доступны в обеих темах, с Controls и документацией.
- [x] Проверены доступность, клавиатура, disabled, форма и узкий экран.
- [x] Формат, lint, типы, тесты, Storybook build и проверки frontend/контрактов проходят.
- [x] Команды и результаты записаны в журнал.

## Границы

Не заменять UI Mini App, не создавать Card/TextField или native-компоненты. Не публиковать Storybook.
Конфигурацию и тесты готовит агент; Card и TextField остаются для совместного кодинга с владельцем.
