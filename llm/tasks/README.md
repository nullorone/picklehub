# Задачи Telegram MVP

Пилот в Москве: 3 дня по 8 часов. Каждая задача — отдельный рабочий шаг с сессиями по 30–60 минут.
План: 20 задач по 60 минут и 4 часа резерва. Оценки предварительные; при перерасходе пересчитывается срок,
а невыполненные критерии не пропускаются.

## Резерв и запуск

Четыре резервных часа третьего дня выделяются на исправления и незавершённые задачи отдельными сессиями
по 30–60 минут. Постоянный пилот требует работающих API, БД и обработчика уведомлений.
GitHub Pages обслуживает frontend; локальный `start:https` даёт HTTPS через mkcert и не создаёт туннель.

Секреты и реальные персональные данные не добавляются в репозиторий. Публикация пилота и реальные
сообщения выполняются только в рамках согласованного запуска/проверки; подготовка не требует публикации.
