# Профиль и статистика: контекст

Публичный профиль показывает display identity, самооценку уровня, форматы, клубы по privacy rules, подтверждённую статистику и достижения после их появления. Возраст не собирается.

DUPR — внешний ID/URL без автоматической синхронизации до официального API. Только confirmed, undisputed match result меняет статистику; гостевые placeholders не получают её.
