# Профиль и статистика: контекст

Публичный профиль показывает отображаемые данные, самооценку уровня, форматы, клубы с учётом правил
конфиденциальности, подтверждённую статистику и достижения после их появления. Возраст не собирается.

DUPR — внешний ID или URL без автоматической синхронизации до появления официального API. Только подтверждённый
и неоспоренный результат матча меняет статистику; гостевые места её не получают.
