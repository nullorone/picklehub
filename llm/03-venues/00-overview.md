# Площадки: контекст

Пользователь ищет публичные pickleball-площадки на карте/в списке или задаёт новый адрес матча. Seed импортируется из OSM с attribution. Пользовательская точка становится кандидатом общего каталога только после состоявшегося матча, дедупликации и модерации.

Точные адреса разрешённых спортивных объектов публичны; частные адреса запрещены. PostGIS отвечает за radius search. Map, tile и geocoder providers скрыты за adapters и используются только по актуальным условиям.
